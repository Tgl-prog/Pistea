# Skills del proyecto

Las skills de motion graphics y vídeo que usa Vallik son plugins instalados en Claude, no archivos de este repo:
- `it-reelsmaker` (IT Reelsmaker + Remotion): reels con el perfil de marca `vallik` y la composición propia `VallikReel.tsx`.
- `animation-studio`: animación 2D dibujada en código.

El código propio (`VallikReel.tsx` y los scripts de Blender y Python del teaser) está en `~/Documents/Vallik/contenido/` (`4-RECURSOS/` y `3-BORRADORES/`; `contenido/PROGRESO.md` dice cuál es la versión buena). El perfil de marca para IT Reelsmaker está en `contenido/4-RECURSOS/sistema-visual/08-reels/perfil-marca-it-reelsmaker/`. Si una skill propia nueva se crea aquí, va en esta carpeta con su SKILL.md.
