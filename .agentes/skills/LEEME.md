# Skills del proyecto

Las skills de motion graphics y vídeo que usa Vallik son plugins instalados en Claude, no archivos de este repo:
- `it-reelsmaker` (IT Reelsmaker + Remotion): reels con el perfil de marca `vallik` y la composición propia `VallikReel.tsx`.
- `animation-studio`: animación 2D dibujada en código.

El código propio (`VallikReel.tsx`, perfil `brands/vallik`, scripts de Blender del teaser) está en el proyecto de claude.ai y Tomás lo baja cuando hace falta a `~/Documents/Vallik/claude/reels/` y `~/Documents/Vallik/claude/teaser/`. Si una skill propia nueva se crea aquí, va en esta carpeta con su SKILL.md.
